## 实现范围

- **评测基线**：`script/benchmark/` 提供带来源／许可／SHA-256 的固定清单，区分调参和留出数据；冻结可执行文件与源码快照；逐图独立进程及双任务批量各重复三次，记录端到端耗时、`wait4` 生命周期峰值 RSS、JSON/CSV 和分类报告。未变小的文件按原大小计入，失败不能从统计中消失。
- **质量基线**：独立 ImageIO 像素比较，以及在计时结束后运行的 SSIM 报告。SSIM 使用完整尺寸、方向校正、sRGB 8 位预乘 RGBA，在黑／白背景合成后分别计算 RGB 通道平均值，取较低分。记录工具哈希、依赖版本和失败结果；不把它称为 SSIMULACRA2 或肉眼无损保证。原始透明 RGB 和 16 位采样另由测试验证。Python 依赖仅用于可选评测，不进入 App。
- **结果对比**：完成任务的按钮和右键菜单可打开对比页；支持分割滑块、Fit／物理像素 1:1、棋盘格／白／深色背景，显示尺寸、实际文件大小及节省比例。尺寸不同时明确说明对齐方式；原图缺失或已覆盖时只显示结果及原因。按需、串行解码，预览最长边 2048，完整解码上限 16 MP／图，文件上限 128 MiB；关闭后不保留图片缓存。保持安全作用域访问配对，并保留任务实际输出目录的授权 URL。
- **对比页界面缩放**：100%、110%、125%、150%，默认 100%，跨重启保存。范围为本页文字和相关控件，不影响图像 1:1、系统窗口元素或导出内容；不足时换行／滚动。没有增加全 App 缩放或快捷键。
- **PNG 优化**：在 ImageIO 完成标准化和编码后，先尝试精确 RGBA 调色板，再有限重新压缩 IDAT；只保留完整文件更小的候选。使用系统 zlib，无新增 App 编码依赖。CLI 的 `--png-imageio-only` 可关闭此步骤用于对照和排查。
- **大小统计修复**：原子替换后改读新鲜文件系统属性，避免 URL 缓存使结果大小和覆盖后的节省统计失真。旧 WebP 基准的 `Peak Mem` 表头更正为实际测量的 `RSS Delta`。

## PNG 策略与边界

优化保留 **ImageIO 已完成结果** 的像素，不把原有的 sRGB 转换也称为无损。精确调色板使用 1/2/4/8 位索引，保留透明像素中未预乘的 RGB。遇到需要翻译的调色板相关元数据时不转换调色板。

编码／解压数据上限均为 64 MiB；共享 250 ms 工作预算。通用重新压缩最多再用 80 ms，只尝试解压数据 <=1 MiB，或解压数据 <=8 MiB 且 IDAT 占比 <=5% 的紧凑流。检查 CRC 和支持的布局；动画、交错、不支持或不安全的未知块回退。预算检查不能中断单次 zlib 操作，不是硬实时上限；不同机器负载下可能选出不同的安全候选。

保留两个压缩任务、autoreleasepool、原有方向／元数据／沙盒／文件保存策略，以及单文件失败隔离。大图和不适合的输入仍使用有效的 ImageIO 结果；不引入有损 PNG 量化。

## 最终评测

环境：arm64，macOS 26.6.2 (25G83)，Xcode 27.0 (27A266a)。GUI 的默认 JPEG 编码与 CLI 的 Advanced JPEG 不同，报告不混用两者。

清单共 **103 张图**：83 张开发样本（包括以前的留出集，均已归入调参集），以及策略冻结后另外选出的 20 张真实留出图。覆盖照片、图标、插画、3D、透明照片，并补充生成的小字、调色板、渐变、透明图、EXIF 方向、P3、HEIC 和 WebP。生成样本的收益不能推断为整个真实素材类别的平均收益。

同一 Release 二进制、相同清单与参数，唯一开关为 PNG 优化。每组 309 次单图测量、3 次完整批量；没有并行运行本项目构建或测试。普通桌面负载仍存在，耗时只作为本机观察，不宣称统计显著。

| 指标 | ImageIO 基线 | 启用 PNG 优化 |
| --- | ---: | ---: |
| 每轮总有效字节数（含未变小文件） | 43,705,402 | 43,524,649 |
| 每轮写出／跳过／失败 | 17 / 86 / 0 | 27 / 76 / 0 |
| 批量耗时中位数 | 2.429 s | 2.843 s |
| 最大批量峰值 RSS | 234.3 MiB | 277.5 MiB |

总有效体积额外减少 **180,753 B（0.414%）**，批量耗时增加约 **17.0%**。开发样本中，生成调色板图总字节减少 87.56%、文字图 13.74%、透明图 20.86%；20 张新真实留出图无额外体积收益。无文件变大。

20 对唯一 PNG 输出的显示像素／透明度检查全部一致；非 PNG 成功输出逐字节不变。SSIM 报告覆盖两组各 103 个样本，无评分失败，两组对应分数完全一致。最低约 0.982605，来自原有 JPEG 重编码；不据此宣称所有有损输出视觉无损。

**采用决定**：启用上述有工作量限制、只选更小结果的优化，收益定位于部分平面／文字／透明素材，接受本机测得的有限额外计算和内存成本；不宣称一般照片或所有 PNG 都能进一步缩小。此前无边界重压缩导致批量时间约翻倍的方案已排除。后续若扩大候选范围，必须重新设留出集并验证收益和成本。
